# Homebrew tap for ysync

Prebuilt [ysync](https://github.com/yetidevworks/ysync) binaries for Apple Silicon and Intel Macs, and ARM64 and x86-64 Linux. Licensed under [MIT](LICENSE).

```sh
brew tap yetidevworks/ysync
brew install yetidevworks/ysync/ysync
ysync --version
```

No GitHub login or Rust toolchain is required. Linux binaries require glibc 2.35 or newer. ysync is experimental; follow the main project's [setup guide](https://github.com/yetidevworks/ysync#connect-two-machines) and evaluate with copies first.

## Updates

```sh
brew update
brew upgrade ysync
```

## Services and monitoring

Configure folders and approve peers before starting the service:

```sh
ysync init
# See the setup guide for folder and peer commands.
brew services start ysync
ysync monitor
```

Stop with `brew services stop ysync`. Use either Homebrew services or ysync's native service commands to manage one daemon. Installation itself does not start a service or synchronize files.

## Maintenance

`Formula/ysync.rb` is generated by `scripts/update_homebrew.py` in the ysync repository from a published release's asset metadata and SHA256SUMS. Every platform checksum must match GitHub's asset digest when supplied. The ysync release workflow updates this tap using a write deploy key scoped only to this repository.

Change the formula template in ysync's `packaging/homebrew/ysync.rb.in`, then run its **Update Homebrew tap** workflow with the release tag. Do not hand-edit the generated formula here.
